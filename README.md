# Enterprise Data Dashboard — RESTful API & Database Architecture

A secure, scalable back-end system that serves API endpoints for enterprise data processing, authentication, and report generation. Powered by Node.js, Express.js, and structured relational database design.

## 🚀 Key Features
- **RESTful API Architecture:** Clean controller-service layer separation handling complex CRUD business logic.
- **Database Architecture (MySQL):** Normalized relational database schema (up to 3NF) ensuring data integrity and zero redundancy.
- **Multi-Role Authentication & Security:** Secure access control implemented via JWT / Sessions and password hashing.
- **Complex Queries & Views:** Optimized SQL queries, joins, and database views for fast analytical reporting.

## 🛠️ Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MySQL / SQL Server
- **Security & Utilities:** JWT, Bcrypt, CORS, Dotenv
